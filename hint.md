## Как открывается страница

Адрес → urls.py → функция в views.py → HTML-шаблон → ответ браузеру.

Например, `/posts/1/` вызывает `post_detail`, которая находит запись с номером
`1` и передаёт её в шаблон `blog/detail.html`.

## Что могут спросить по коду

### Главная страница

В `blog/views.py`:

```python
return render(request, 'blog/index.html', {'posts': posts[::-1]})
```

- `request` — запрос пользователя.
- `render` — собирает HTML из шаблона и данных и возвращает ответ.
- `'blog/index.html'` — нужный шаблон.
- `{'posts': ...}` — контекст, то есть данные для шаблона.
- `posts[::-1]` — список в обратном порядке, чтобы последние записи были первыми.

### Поиск отдельной записи

```python
def post_detail(request, id):
    for post in posts:
        if post['id'] == id:
            return render(request, 'blog/detail.html', {'post': post})
    raise Http404('Публикация не найдена')
```

Перебираем записи и сравниваем их `id` с номером из адреса. Если нашли — показываем
запись. Если нет — возвращаем ошибку 404. `raise Http404` находится после цикла:
ошибка нужна, только если просмотрели все записи и ничего не нашли.

`posts` — список, а каждый `post` внутри него — словарь. Например,
`post['id']` получает значение по ключу `id`.

### Маршрут и его имя

В `blog/urls.py`:

```python
path('posts/<int:id>/', views.post_detail, name='post_detail')
```

`<int:id>` принимает целое число из адреса и передаёт его функции как `id`.
`name` — имя маршрута, по которому можно создавать ссылки.

```python
app_name = 'blog'
```

Это пространство имён приложения. Полное имя маршрута — `blog:post_detail`.
Так можно отличать маршруты разных приложений с одинаковыми именами.

В главном `urls.py` функция `include` подключает маршруты приложений.
Префикс `pages/` добавляется к адресам из `pages/urls.py`, поэтому получается,
например, `/pages/about/`.

### Вывод данных в HTML

В `templates/blog/index.html`:

```django
{% for post in posts %}
  <p>{{ post.text|truncatewords:10 }}</p>
{% endfor %}
```

- `{% for %}` — перебор записей.
- `{{ post.text }}` — вывод текста из словаря.
- `truncatewords:10` — оставить первые десять слов.

На отдельной странице выводится полный текст. Фильтр `linebreaksbr` превращает
переносы строк в HTML-теги `<br>`.

Ссылка на пост создаётся так:

```django
{% url 'blog:post_detail' post.id %}
```

Здесь передаётся имя маршрута и номер записи. Django сам собирает адрес.

### Общий шаблон base.html

В нём находятся меню, подключение CSS, основная разметка и подвал.
Другие шаблоны используют его:

```django
{% extends "base.html" %}
{% block content %}
  ...
{% endblock %}
```

`extends` подключает родительский шаблон, а `block content` задаёт содержимое
конкретной страницы. Так общую разметку не приходится повторять.

### Настройки и статика

В `settings.py`:

- `INSTALLED_APPS` — подключённые приложения, в том числе `blog` и `pages`.
- `TEMPLATES`, параметр `DIRS` — где искать общую папку шаблонов.
- `STATICFILES_DIRS` — где лежат CSS и картинки.

В шаблоне `{% load static %}` подключает теги для статики,
а `{% static 'css/bootstrap.min.css' %}` создаёт путь к CSS-файлу.

## Короткие ответы

- **Где хранятся публикации?** В списке `posts` в `blog/views.py`, как требует
  задание. Из базы они не читаются.
- **Что такое slug?** Текстовая часть адреса, например `travel` или `not-my-day`.
- **Почему в категории нет постов?** По заданию пока нужно вывести только
  название категории из адреса.
- **Почему к дате не применён фильтр date?** Дата в задании хранится строкой,
  а не объектом даты.
- **Чем отличаются blog и pages?** `blog` отвечает за публикации,
  `pages` — за информационные страницы.
- **Что проверяет pytest?** Запускает тесты, которые проверяют поведение проекта.
- **Что проверяет flake8?** Стиль Python-кода и некоторые ошибки,
  например неиспользуемые импорты. Работу сайта он не проверяет.
- **Зачем migrate?** Создаёт таблицы стандартных приложений Django.
  Публикации в этом задании всё равно остаются в списке.

## Как подготовиться

1. Проследи открытие `/posts/1/` от маршрута до шаблона.
2. Объясни каждую строку `post_detail` своими словами.
3. Разберись, чем отличаются `posts` и `post`, что такое список и словарь.
4. Попробуй добавить четвёртый пост с новым `id` и открыть его в браузере.
   После тренировки верни исходные три записи: тесты сравнивают их с заданием.
5. Найди в шаблоне ссылку на категорию и объясни, откуда берётся её адрес.
